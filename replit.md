# tg-reactionmonitor

Telegram bot for monitoring reactions and analyzing the sentiment (tonality) of news in Telegram channels.

## Setup

1. Get a bot token from [@BotFather](https://t.me/BotFather) on Telegram.
2. Set the `BOT_TOKEN` environment variable (in Replit Secrets or a `.env` file).
3. Run the bot with `python main.py`.

## Project Structure

- `main.py` — bot entry point with command handlers
- `requirements.txt` — Python dependencies
- `.env.example` — example environment variable file

## User preferences

- Language: Russian (project documentation and bot messages are in Russian)
